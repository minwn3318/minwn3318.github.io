### 트러블슈팅
**문제** : 화면을 어떻게해야 버튼이 눌렸을 때 바뀌는지 방법을 몰랐음   
**해결방법** : 웹 서칭, ai를 사용하여 react의 state와 이벤트 리스너를 알게되어 이벤트 리스너가 state의 함수명을 이용해 state값을 변경하여 화면 변화를 이끌어 냄   
**느낀점** :    
1. react내용 안다고 생각했는데 모르는 부분도 많다는 걸 느껴 기술블로그에 적으며 공부해야겠따 생각했다
2. 한번에 만드려하지 말고 차근차근 디버깅하며 만드는 습관을 가지자. 웹화면의 차근차근 만드는 게 조금 덜 익숙하다

### 알게 된 점
if가 0아니면 1인 상태라면 배타적 관계이기 때문에, 삼항으로 표시해도 괜찮음   
   
```
if(a === "a"){
    a = "b"
}
if(a === "b"){
    a = "a"
}

-------<다음과 같이 수정 가능>---------

a => a === "a" ? "b" : a

```
> 공부할 거
> - state
> - array, map, 객체
> - 컴포넌트 
> - 이벤트 리스너
> - react외 nest나 vue에 대해 간단히 알아보기
