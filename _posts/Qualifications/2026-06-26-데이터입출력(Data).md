# 정보처리기사 - 데이터 입출력 구현

해당 포스트에서는 정보처리기사 개념문제집 2장 **데이터 입출력 구현**을 정리한다
## 자료구조
### 배열
> 크기와 형이 동일한 자료들이 순서대로 나열된 자료의 집합이다
- 반복적인 데이터 처리 작업에 적합한 구조이다
- 정적인 자료 구조로, 기억장소의 추가가 어렵다
- 데이터 삭제 시 기억장소가 빈 공간으로 남아있어 메모리의 낭비가 발생한다

### 연속 리스트
> 연속되는 기억 자옷에 저장되는 자료구조이다
- 중간에 데이터를 삽입하기 위해서는 연속된 빈공간이 있어야 한다
- 삽입 삭제 시 자료의 이동이 필요하다

### 연결 리스트
> 자료들의 임의의 기억공간에 기억시키되 자료 항목의 순서에 따라 노드의 포인터 부분을 이용하여 서로 연결시킨 자료구조이다
- 연결을 위한 링크 부분이 필요하기 때문에 기억 공간의 이용 효율이 좋지 않다

### 스택
> 리스트의 한쪽 끝으로만 자료의 삽입, 삭제 작어빙 이루어지는 자료구조이다
- 후입선출 방식으로 자료를 처리한다
- 저장공간이 없는데 젖아하면 오버플로, 삭제할 내용이 없는데 삭제하면 언더플로가 발생한다

### 큐
> 리스트의 한쪽에서는 삽입 작업이 이루어지고 다른 한쪽에서는 삭제 작업이 이루어지는 자료구조
- 선입 선출 방식으로 처리한다
- 시작을 표시하는 프런트 포이넡와 끝을 표시하는 리어 포인터가 있다

## 트리 관련 용어
- 노드
> 트리의 기본 요소로서 자료 항목과 다른 항목에 대한 가지를 합친 것
- 근노드
> 트리의 맨 위에 있는 노드
- 디그리
> 각 노드에서 뻗어나온 가지의 수
- 단말노드
> 자식이 하나도 없는 노드
- 레벨
> 근 노드를 기준으로 1이라 하고, 아래 계속이어지는 자식 노드 층
- 깊이
> 최대 레벨
- 숲
> 여러 개의 트리가 보여있는 것
- 트리의 디그리
> 노드들의 디그리 중에서 가장 많은 수

### Preorder 운행법
- 루트 -> 왼쪽 -> 오른족 순으로 운행하며 노드를 찾아감

### Inorder 운행법
- 왼쪽 -> 루트 -> 오른쪽 순으로 운행하며 노드를 찾아감

### Postorder 운행법
- 왼쪽 -> 오른쪽 -> 루트 순으로 운행하며 노드를 찾아감

## 삽입 정렬
> 이미 순서화된 파일에 새로운 하나의 레코드를 순서에 맞게 삽입시켜 정렬하는 방식

### 선택 정렬
> 최소값을 찾아 첫번째 레코드 위체 놓고 나머지 중에서 다시 최소값을 찾아 두 번째 레코드 위치에 놓는 방식을 반복하여 정렬하는 방식

### 버블정렬
> 인접한 두 개의 레코드 키 값을 비교하여 그 크기에 따라 케로크 위치를 서로 교환하는 정렬 방식

### 퀵 정렬
> 키를 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽 서브 파링레 분해시키는 과저을 반복하는 정렬 방식
